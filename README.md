# Austone Thailand

ระบบสะสมแต้มสำหรับยางรถยนต์ Austone ผู้ใช้สแกนบาร์โค้ดที่ยางเพื่อรับแต้ม แล้วนำแต้มไปแลกของรางวัล ส่วนแอดมินจัดการบิล สินค้า ผู้ใช้ และของรางวัลได้จากหลังบ้าน

## ระบบนี้ทำอะไรได้บ้าง

**ผู้ใช้ทั่วไป**

- สมัครสมาชิกและเข้าสู่ระบบ
- สแกนบาร์โค้ดหรือพิมพ์รหัสสินค้าเพื่อสะสมแต้ม
- ดูประวัติการสะสมแต้ม
- แลกของรางวัล
- แก้ไขข้อมูลส่วนตัว

**แอดมิน**

- ดูภาพรวมที่หน้าแดชบอร์ด
- จัดการบิล ผู้ใช้ สินค้า และของรางวัล
- ดูประวัติแต้มและประวัติการแลกของรางวัล
- ตั้งค่าระบบ

## เริ่มใช้งานบนเครื่อง

### 1. เตรียมเครื่องมือ

- [Node.js](https://nodejs.org) เวอร์ชัน 24 (โปรเจกต์นี้ใช้ 24.10.0)
- [Yarn](https://classic.yarnpkg.com) เวอร์ชัน 1

ถ้าใช้ nvm พิมพ์คำสั่งนี้ในโฟลเดอร์โปรเจกต์ แล้วเครื่องจะเลือกเวอร์ชันที่ถูกต้องให้

```bash
nvm use
```

### 2. ติดตั้งแพ็กเกจ

```bash
yarn install
```

### 3. ตั้งค่าระบบ

สร้างไฟล์ `.env.local` ไว้ที่โฟลเดอร์หลักของโปรเจกต์ แล้วใส่ค่าตามตารางด้านล่าง ขอค่าจริงได้จากผู้ดูแลระบบ

> ห้าม commit ไฟล์นี้ และห้ามส่งค่าในไฟล์นี้ให้คนนอกทีม เพราะมีรหัสลับของระบบ

| ชื่อค่า | ใช้กับ |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_PROJECT_ID` | ฐานข้อมูล Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ฐานข้อมูล Supabase |
| `SUPABASE_SERVICE_KEY` | ฐานข้อมูล Supabase (สิทธิ์แอดมิน) |
| `RESEND_API_KEY` | ส่งอีเมลไฟล์ PDF ของบิล |
| `TWILIO_ACCOUNT_SID` | ส่งรหัส OTP |
| `TWILIO_AUTH_TOKEN` | ส่งรหัส OTP |
| `TWILIO_SERVICE_SID` | ส่งรหัส OTP |
| `NEXT_PUBLIC_LINE_CHANNEL_ID` | เข้าสู่ระบบด้วย LINE |
| `LINE_CHANNEL_SECRET` | เข้าสู่ระบบด้วย LINE |
| `LINE_OAUTH_ENDPOINT` | เข้าสู่ระบบด้วย LINE |
| `EASY_SLIP_API_KEY` | มีกำหนดไว้ในระบบ แต่โค้ดยังไม่ได้เรียกใช้ |

### 4. เปิดระบบ

```bash
yarn dev
```

เปิดเบราว์เซอร์ไปที่ <http://localhost:3000/auth/sign-in>

## คำสั่งที่ใช้บ่อย

| คำสั่ง | ทำอะไร |
| --- | --- |
| `yarn dev` | เปิดระบบสำหรับพัฒนา |
| `yarn build` | สร้างไฟล์สำหรับใช้งานจริง |
| `yarn start` | เปิดระบบจากไฟล์ที่ build แล้ว |
| `yarn lint` | ตรวจคุณภาพโค้ด |
| `yarn test` | รันการทดสอบ |

## โครงสร้างโปรเจกต์

| โฟลเดอร์ | เก็บอะไร |
| --- | --- |
| `app/user` | หน้าของผู้ใช้ทั่วไป |
| `app/admin` | หน้าของแอดมิน |
| `app/auth` | หน้าเข้าสู่ระบบ สมัครสมาชิก และลืมรหัสผ่าน |
| `features` | โค้ดแยกตามฟีเจอร์ เช่น บิล สินค้า และบาร์โค้ด |
| `components` | ส่วนประกอบหน้าจอที่ใช้ร่วมกัน |
| `actions`, `services` | โค้ดฝั่งเซิร์ฟเวอร์ |
| `lib`, `hooks` | ฟังก์ชันช่วยเหลือ |
| `config` | การอ่านค่าจาก environment |

## การนำขึ้นใช้งานจริง

ระบบนี้รันอยู่บน [Vercel](https://vercel.com) และใช้ Node.js 24 ตามค่า `engines` ใน `package.json`

```bash
vercel          # นำขึ้น preview เพื่อทดสอบก่อน
vercel --prod   # นำขึ้นใช้งานจริง
```

ค่าใน `.env.local` ต้องตั้งใน Project Settings ของ Vercel ด้วย เพราะไฟล์นี้ไม่ถูกส่งขึ้นไป

## แก้ปัญหาที่พบบ่อย

**`next: command not found`**

แพ็กเกจยังติดตั้งไม่สำเร็จ ให้รัน `yarn install` แล้วดูว่ามี error หรือไม่

**`The engine "node" is incompatible with this module`**

Node.js ในเครื่องไม่ตรงกับที่โปรเจกต์กำหนด ให้เช็กด้วย `node -v` แล้วเปลี่ยนเป็นเวอร์ชัน 24
